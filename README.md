# 🌐 MyAcademyPortfolioCore (.NET 9.0)

Merhaba! 👋  
Bu proje, **M&Y Akademi Danışmanlık** çatısı altında sevgili hocamız **Erhan Gündüz**’ün rehberliğinde ASP.NET Core eğitimi süresince geliştirilmiştir.  
Amacımız, öğrendiklerimizi pekiştirirken **.NET 9.0 tabanlı dinamik bir Portfolio & CV uygulaması** ortaya koymaktır.  

---

## ⚙️ Teknik Özellikler

- **ASP.NET Core MVC**
  - Çok katmanlı yapı  
  - Controller – Model – View ayrımı  
  - Dependency Injection desteği  

- **Entity Framework Core**
  - Code First yaklaşımı  
  - Migration & LINQ desteği  
  - Repository kullanımı  

- **View Components & Partial Views**
  - Dinamik içerik yönetimi  
  - Tekrar kullanılabilir bileşenler  

- **Katmanlı Mimari**
  - Entity Layer → Veri modelleri  
  - Data Access Layer → EF Core repository’ler  
  - Business Layer → İş kuralları  
  - Presentation Layer → MVC (Controller + View)  

- **Responsive UI**
  - Bootstrap 5  
  - Mobil uyumluluk  

---

## 📌 Modüller

- **Home / Dashboard** → Banner, istatistikler, hakkımda  
- **Portfolio** → Proje listeleme  
- **Skills** → Yetenek grafikleri (progress bar)  
- **Experience / Education** → Zaman çizelgesi (timeline)  
- **Contact** → İletişim formu, mesaj kaydı  
- **Admin Panel** → CRUD işlemleri, içerik yönetimi  

---

## 🛠 Kullanılan Teknolojiler

- .NET 9.0  
- ASP.NET Core MVC  
- Entity Framework Core  
- SQL Server  
- Bootstrap 5  
- LINQ
